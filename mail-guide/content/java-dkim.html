java - DKIM 붙여서 메일 발송 하기

SPF 를 적용했는데도 수신측에서 메일을 잘 받아 주지 않는다면 DKIM 적용을 검토합니다.

개요

  • 메일을 많이 보내게 되면 수신측의 스팸 정책에 따라서 메일을 잘 안받아 주는 경우가 생긴다.
  • SPF 를 적용해 주면 어느정도 효과가 있지만, SPF 를 이미 적용했는데도 잘 안받아 주면 DKIM 을 적용해 보는 것이 좋다.
