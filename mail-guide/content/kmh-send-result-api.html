발송결과확인 API

kmh 를 사용할 경우 발송 결과 확인 API 로 발송결과를 확인해 볼 수 있습니다.

향후 변경될(cstool-kmh) kmh 발송로그조회 API

22년 11월 베타테스트 22년 12/12 오픈확정

API domain/path는 변경되지만, client 변경을 최소화하기 위해 가급적 기존 response body는 유지함.

Request Path
GET http://mail-kmh.onkakao.net/v1/kmh/sendlogs

request parameter

⚠️
API 조회시 주의사항
  1. 조회시 from / to 파라미터는 반드시 있어야 함. (필수)
  2. 조회 시작과 끝날짜가 없다면 기본적으로 현재날짜 기준 “7일전”까지만 조회됨.
  3. 조회시작날짜가 조회끝날짜 이전이어야 함.
  4. 조회가능날짜범위는 현재날짜부터 31일 전까지임 (한달만 조회 가능)
    • startDate / endDate 는 현재날짜부터 31일 이전은 조회 불가능
    • 예: 현재날짜가 2022년 2월 7일이라면 startDate / endDate 는 2022년 1월 7일 이후만 가능
nametype필수여부description예시값
fromstringrequired 조회할 발신자 이메일주소.noreply@kakocorp.com
tostringrequired 조회할 수신자 이메일 주소poet.me@kakaocorp.com
startDatestringoptional 조회시작날짜(yyyymmdd), 조회끝날짜(endDate) 없으면 조회끝날짜는 현재날짜로 세팅됨20220101
endDatestringoptional 조회끝날짜(yyyymmdd), 조회시작날짜(startDate) 없으면 조회시작날짜는 현재날짜부터 7일전으로 세팅됨20220130

현재 서비스중인 kmh 발송로그조회 API 2022.12.11 종료예정

⚠️
현재 사용중인 API는 향후 위에 변경될 API 로 적용될 예정이오니 변경개발 부탁드립니다.
Request Path
GET http://api.kmh.daumkakao.io/v1.3/sendlogs?to=<수신자이메일>

results 에 list 로 결과정보가 나옵니다.

Response Body
{
    "results" : [
        "from"            : string     // 발송자 이메일 주소
        "to"              : string     // 수신자 이메일 주소
        "result"          : string     // 발송 결과 (ex. FAIL, SUCCESS)
        "message"         : string     // 결과 메시지 - 실패 원인 확인 용도
        "sender"          : string     // 발송 서비스 서버
        "receiver"        : string     // 전송된 메일서버
        "receiverRelayTo" : string     // 전송 목적지 서버. 현재 메일을 외부로 발송하는 서버로
                                       //   내부로 발송한 경우는 값이 없다.
        "recvdttm"        : string     // receiver 서버가 받은 시각
        "destination"     : string     // 최종 전달 경로
        "sentdttm"        : string     // 최종 발송 시각
    ],
    "offset" : string  // 조회 해 온 데이터 이후에 데이터가 더 있는 경우 offset 값이 있음.
                       // offset 값이 있으면 이후 데이터를 조회 하고 싶으면
                       // request parameter 에 offset 값을 넣어서 조회 한다.
}
