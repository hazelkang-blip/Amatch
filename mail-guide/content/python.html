python 에서 메일발송서버 이용 방법 예시

개요

  • python 에서 메일발송서버 이용 방법 예시
  • smtplib.SMTPException 처리하는 다양한 예시는 http://www.programcreek.com/python/example/3945/smtplib.SMTPException 를 참조하세요.

예제

MIMEText 를 이용한 예제. 일반적인 방식

python
#!/usr/bin/python
# -*- coding: utf-8 -*-
import smtplib
from email.mime.text import MIMEText
from email.header import Header

contents = "안녕하세요.<br />메일파트 june.kim 입니다."
msg = MIMEText(contents, 'html', 'utf-8')

sender = "mta1test@daum.net"
receiver = "wwl1401test@daum.net"
subject = "제목입니다."

msg['Subject'] = Header(subject, "utf8")
msg['From'] = sender
msg['To'] = receiver

host = "mail-kmh-relay.daumkakao.io"
port = 25

smtp = smtplib.SMTP(host, port)
smtp.set_debuglevel(1)
smtp.sendmail(sender, receiver, msg.as_string())

text 메일 발송 예제

⚠️
아주 심플한 메일을 날릴 때만 사용함. 인코딩 지정을 안해서 수신 서버에 따라 인코딩 문제가 생길 수 있음. 이 방식 이용시 가급적 영문 메일만 작성 하도록 한다.
python
#!/usr/bin/python
#*-* coding: UTF8 -*-
import smtplib

host = "mail-kmh-relay.daumkakao.io"
port = 25

smtp = smtplib.SMTP(host, port)
smtp.set_debuglevel(0)
smtp.sendmail("wwl1400test@daum.net", "wwl1401test@daum.net",
              "From: wwl1400test@daum.net\nTo: wwl1401test@daum.net\nSubject: python mail test2\n\nthis is contents")
smtp.quit()

SMTP 커맨드를 직접 날리는 예제

SMTP 프로토콜 레벨수준에서 디버깅이 필요한 경우 사용. 일반적으로 잘 사용 하지 않는다.

python
#!/usr/bin/python
#*-* coding: UTF8 -*-
import smtplib

host = "mail-kmh-relay.daumkakao.io"
port = 25

smtp = smtplib.SMTP(host, port)
smtp.set_debuglevel(0)
smtp.ehlo()
smtp.docmd("MAIL FROM: wwl1400test@hanmail.net")
smtp.docmd("RCPT TO: wwl1401test@hanmail.net")
smtp.docmd("DATA")
smtp.docmd("Subject: this is test mail for python\n\nthis is contents\n\n.")
smtp.quit()

2014.10.07 MIMEText 모듈과 Content-Type 이슈

  • 아지트 글
  • html 타입의 문서를 발송 하는데 Content-Type 을 지정 해 주었지만 깨짐. MIMEText 생성 할 때 Content-Type 이 이미 생성되었기 때문임.

아래와 같이 인코딩을 잘 명시 해 준다.

python
msg = MIMEText(contents, 'html')
msg.set_charset("utf-8")

# or

msg = MIMEText(contents, 'html', 'utf-8')
