다른버전 이용자를 위한 가이드

사내 메일 발송 라이브러리가 크게 두 갈래로 나뉘어 있습니다. 두 계열의 차이점과 마이그레이션 방법을 정리했습니다.

다른버전 이용자를 위한 가이드

  • 라이브러리가 크게 두가지 갈래를 가지고 있는 것으로 보입니다. (오래된 히스토리라 파악이 힘드네요)
  • 현 메일팀의 라이브러리와는 다소 차이가 있는 거 같아 차이점에 대해 다뤄 보는 페이지를 만들었습니다.
  • 만약 마이그레이션을 하게 되면 꼼꼼하게 테스트 부탁드립니다.
  • 보충할 내용이 있으시면 댓글 등으로 제보 부탁드립니다.
⚠️
라이브러리를 모두 까보고 테스트 해 본것이 아니기 때문에 일부 내용이 틀리거나 오류가 있을 수 있습니다. 제보 부탁드립니다.

2005년 개발자 포럼을 통해 배포된 버전

  • 개발자 포럼을 통해 배포된 것으로 보입니다.
  • setToHeader, setReplyFlag, setEnvFromNullAccount 함수가 존재하며 send() 함수의 리턴타입이 int 입니다.
  • 여러팀을 거쳐 다양한 maven 위치에 존재하는 것으로 보입니다.

검색유닛

xml — pom.xml
<dependency>
  <groupId>net.daum.search</groupId>
  <artifactId>daum_mail_old</artifactId>
  <version>1.0</version>
  <scope>compile</scope>
</dependency>

비즈개발유닛

xml — pom.xml
<dependency>
  <groupId>net.daum</groupId>
  <artifactId>daum_mail</artifactId>
  <version>1.0</version>
</dependency>

현재 메일팀에서 배포하고 있는 버전

  • http://play.daumcorp.com/pages/viewpage.action?pageId=169347419
  • setToHeader, setReplyFlag, setEnvFromNullAccount 함수가 존재하지 않으며 send() 함수의 리턴타입이 String 입니다.
  • 2010년 이홍연님의 버전으로 시작된 것으로 보이며 http://play.daumcorp.com/display/~lotus/daum_mail.jar
  • 2011년 황현천님과 김재영님을 통해 maven 등록 된 것으로 보입니다. http://play.daumcorp.com/pages/viewpage.action?pageId=43355791

현재 메일팀에서 배포하는 버전으로 바꾸고 싶다면

msg.setReplyFlag(false); 와 msg.setEnvFromNullAccount(true); 는 삭제

java — 삭제 대상
msg.setReplyFlag(false);
msg.setEnvFromNullAccount(true);
  • 해당 코드의 역할은 mail from 주소를 returnmaster@hanmail.net 으로 바꾸어 주는 역할을 합니다. (header from 은 바꾸지 않습니다.)
  • 테스트 해 본 결과 header from 은 바뀌지 않기 때문에 위 두 줄을 다른 코드로 대체하려 하시면 안됩니다.
  • 그냥 위의 두 줄을 삭제 해 주시면 됩니다.

send 함수의 리턴값

  • 메일 발송 후 최종 결과 정보를 String 으로 리턴 합니다.
return value
250 2.0.0 s24AXc3t019941 Message accepted for delivery
  • 정상적으로 값을 리턴 받았다면 성공으로 판단하시면 됩니다.
  • 그렇지 않다면 HMException 이 발생하기 때문에 해당 예외처리를 catch 하면 실패로 판단하시면 됩니다.

base64Encoder 관련 부분

  • 메일팀에서 배포중인 라이브러리에서는 해당 기능을 내장하고 있기 때문에 관련 처리 부분은 모두 삭제 해 주시면 됩니다.

hmmsg.setContentType("text/html; charset=\"EUC-KR\""); 삭제

java — 삭제 대상
hmmsg.setContentType("text/html; charset=\"EUC-KR\"");
  • 구 라이브러리에서는 euc-kr 을 사용했지만 현재 라이브러리는 UTF-8 을 사용합니다.
  • 해당 라인은 삭제 해 주시면 됩니다. 단, 내용도 UTF-8 로 변환시켜 주시기 바랍니다.
