Apache Commons Email

Apache Commons Email 라이브러리를 이용한 메일 발송 예제입니다.

개요

  • https://commons.apache.org/proper/commons-email/
  • http://commons.apache.org/proper/commons-email/userguide.html
  • https://mvnrepository.com/artifact/org.apache.commons/commons-email
xml — pom.xml
<dependency>
    <groupId>org.apache.commons</groupId>
    <artifactId>commons-email</artifactId>
    <version>1.5</version>
</dependency>

일반 메일 발송 예제

java — SimpleEmail
Email email = new SimpleEmail();
email.setHostName("mail-kmh-relay.daumkakao.io");
email.setFrom("notice-master@daum.net");
email.setSubject("TestMail");
email.setMsg("This is a test mail ... :-)");
email.addTo("wwl1401test@daum.net");
email.send();

첨부 파일 메일 발송 예제

java — MultiPartEmail
// Create the attachment
EmailAttachment attachment = new EmailAttachment();
attachment.setPath("mypictures/john.jpg");
attachment.setDisposition(EmailAttachment.ATTACHMENT);
attachment.setDescription("Picture of John");
attachment.setName("John");

// Create the email message
MultiPartEmail email = new MultiPartEmail();
email.setHostName("mail-kmh-relay.daumkakao.io");
email.addTo("wwl1401test@daum.net", "wwl1401test");
email.setFrom("mta1test@daum.net", "mta1test");
email.setSubject("The picture");
email.setMsg("Here is the picture you wanted");

// add the attachment
email.attach(attachment);

// send the email
email.send();
